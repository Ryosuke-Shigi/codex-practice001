## 目的

LumiLaboは上位プロダクト / 上位ドメインとして扱う。
最初に扱うサブシステムは案件システムとし、現在の実作業は案件システム IDEA BOARD をブラウザで確認できる状態にすること。

## 現在のIDEA BOARD

- 画面: `/lab/lumilabo-project-idea-board`
- 必須タブ: TOP / 案件 / 案件作成 / 案件一覧 / Coding
- 初期表示: TOP
- 中心: 案件タブは案件システム概要、案件作成タブは最初の入力入口、案件一覧タブは1案件カードの一覧構想
- 対象外: MOCK / PRODUCT / DB / Migration / Backend本実装 / カレンダー
