# LumiLabo 案件システム MOCK

- Status: active
- Scope: LumiLabo / 案件システム MOCK
- Last reviewed: 2026-07-07
- Canonical source: `/lab/lumilabo-project-mock` の初期導線と画面範囲

## 目的

LumiLabo 案件システム MOCK は、お客様に実際の画面導線を見てもらうための仮UIとして扱う。

IDEA BOARDは機能説明資料、MOCKは画面確認であり、MOCK側へIDEA BOARDの通常リンクや説明資料への戻り導線を置かない。

現在のMOCKでは、TOPから案件システムへ入る最小導線を維持しつつ、一覧から案件詳細へ進む最小導線と案件詳細単体のUIを確認する。

## 現在の導線

```text
TOP
  ↓ Start
選択
  ├ 案件 → 案件TOP
  │          ├ 登録
  │          └ 一覧 → 詳細を見る → 案件詳細 → 戻る → 一覧
  └ TOPへ戻る → TOP
```

## 画面構成

全体タブ:

- TOP
- 選択

案件内タブ:

- TOP
- 登録
- 一覧

案件TOP通常ボタン:

- 登録
- 一覧
- 戻る

案件詳細は案件内タブではなく、一覧から進む内部表示として扱う。戻るもファイルタグへ混ぜず、案件詳細内の通常ボタンとして一覧へ戻す。

工程デッキ、工程カード、カレンダーは、ユーザーが明示した段階で追加する。現在の標準タブには含めない。

## TOP

TOPでは、LumiLaboの入口だけを見せる。

見せるもの:

- LumiLaboアイコン
- LumiLaboタイトル
- Startボタン

置かないもの:

- 案件説明
- IDEA BOARDリンク
- 一覧 / 登録 / 詳細への直接導線
- 実データに見える数値や進捗

## 選択

選択では、LumiLabo配下のサブシステムを選ぶ。

現在見せるもの:

- Primaryの案件ボタン / 案件カード
- SecondaryのTOPへ戻るボタン

現在は、案件以外のサブシステムを増やさない。
TOPへ戻るはMOCK内のUI状態をTOPへ戻すだけで、DB保存、API通信、Inertia遷移、route追加は行わない。

## 案件TOP

案件TOPでは、案件システムに入ったことと、案件内で確認する画面を見せる。

見せるもの:

- 案件アイコン
- 案件タイトル
- 登録 / 一覧 の通常ボタン
- 選択画面へ戻るボタン

戻るボタンは案件TOPに置き、選択画面へ戻る。登録画面と一覧画面でも、画面内の通常ボタンとして選択画面へ戻るボタンを置く。

## 登録

登録タブでは、案件登録画面の System UI MOCK を確認する。

現在の登録タブで扱う項目:

- 会社名
- 担当者名
- 住所
- メモ

会社名、担当者名、住所、メモは入力UIとして見せる。
住所は1つの入力項目として扱い、郵便番号 / 都道府県 / 市区町村へ勝手に分割しない。
登録するボタンの次に、選択画面へ戻るボタンを置く。

登録タブで扱わないもの:

- 登録日時
- 登録日表示
- ステータス表示
- ステータス選択
- 案件名
- 郵便番号
- 都道府県
- 市区町村
- 住所の分割入力
- DB保存
- API通信
- Inertia送信
- 保存可能な本番フォーム
- Controller / Request / Action / Service / Repository / DTO / Responder の本実装

登録画面はMOCKであり、PRODUCTの保存フォームではない。
登録ボタンはMOCK上の見た目に留め、DB保存、API通信、Inertia送信、保存後遷移は行わない。

## 一覧

現在のMOCKでは、一覧は案件内の画面選択として扱う。

一覧では、案件を選択するための最小固定データ1件と、通常ボタンの「詳細を見る」だけを置く。案件詳細フォーム、地図風プレビュー、写真撮影、ファイルD&D、保存ボタンは一覧へ混ぜない。

## 案件詳細

案件詳細は一覧とは別の内部表示として扱う。詳細はファイルタグへ追加しない。

現在の案件詳細で扱う項目:

- 会社名
- 担当者名
- 住所
- メモ
- 登録日
- 地図風プレビュー
- 写真撮影ボタン
- ファイル複数ドラッグアンドドロップ欄
- 保存済み写真プレビュー
- 保存済みファイルプレビュー

会社名、担当者名、住所、メモはReact内stateで編集する。登録日は表示のみで、編集対象や保存対象にしない。

保存ボタンは、会社名、担当者名、住所、メモのいずれかが編集された場合だけ画面上部へ表示する。保存はMOCK上のReact内state反映に留め、保存完了後は上部に「保存しました」を表示して自動で消す。

地図風プレビューは固定UIで、Google Maps API、Geocoding API、Embed APIは使わない。クリック時は保存済み住所をURLエンコードして `https://www.google.com/maps/search/?api=1&query=...` を別タブで開く。

保存済み写真、保存済みファイルは存在する場合だけ見出しとプレビューを表示する。0件の場合は見出し、枠、空表示を出さない。

- 工程デッキ
- 工程カード
- カレンダー
- DB / Migration / Model
- Controller / Request / Action / Service / Repository / DTO の本実装
- API通信
- 保存可能フォーム
- 登録日時の登録画面表示
- ステータスの登録画面表示 / 選択
- 案件名
- 住所分割
- 実データに見える数値、件数、進捗
- 本番アップロード
- S3保存
- カメラ本実装
- Google Maps API / Geocoding API / Embed API

## 確認観点

- TOP → Start → 選択 → 案件 → 案件TOP の導線になっていること
- 選択で案件とTOPへ戻るを選べること
- 選択のTOPへ戻るでTOPへ戻れること
- TOPは LumiLabo / Start の入口だけになっていること
- 選択はPrimaryの案件ボタン / 案件カードとSecondaryのTOPへ戻るボタンだけになっていること
- 案件内タブが TOP / 登録 / 一覧、案件TOP通常ボタンが 登録 / 一覧 / 戻る であること
- 案件TOPはモバイル縦で上寄せ、スマホ横では通常ボタンと戻るが見切れないこと
- 登録 / 一覧画面の戻るが通常ボタンで、ファイルタグへ混ざっていないこと
- 登録タブで会社名 / 担当者名 / 住所 / メモが表示されること
- 登録タブに登録日時 / 登録日表示が出ていないこと
- 登録タブにステータスが出ていないこと
- 登録タブに案件名が出ていないこと
- 住所が分割入力になっていないこと
- 案件TOPの戻るボタンで選択へ戻れること
- 詳細が案件内タブへ追加されていないこと
- 戻るが案件内タブへ追加されていないこと
- 一覧に案件詳細フォーム、地図風プレビュー、写真撮影、ファイルD&D、保存ボタンが混ざっていないこと
- 一覧の「詳細を見る」で案件詳細へ進めること
- 案件詳細の戻るで一覧へ戻れること
- 案件詳細で会社名 / 担当者名 / 住所 / メモを編集できること
- 案件詳細の保存ボタンは編集後だけ表示されること
- 案件詳細の保存後に「保存しました」が上部に表示され、自動で消えること
- 登録日は編集不可で、保存対象外であること
- 地図風プレビューがGoogle Maps検索URLを別タブで開くこと
- Google Maps API / Geocoding API / Embed APIを使っていないこと
- 写真撮影ボタンがPC / タブレット / モバイルで表示されること
- 保存済み写真 / ファイルが0件の場合は見出し、枠、空表示が出ないこと
- IDEA BOARDへの通常リンクをMOCK内に置いていないこと
- スマホ横置きで案件TOPの戻るボタンが見切れないこと
- DB / Backend本実装 / API通信へ踏み込んでいないこと
